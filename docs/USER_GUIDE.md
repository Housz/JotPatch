# JotPatch 用户指南

JotPatch（**随地大小贴**）在原网页附近保存轻量便签，便签内容储存在你的浏览器扩展本地存储中。

## 安装

### Chrome / Edge

1. 下载该平台的 ZIP 并完整解压。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
3. 选择「加载已解压的扩展程序」，选中**直接包含 `manifest.json`** 的目录。不能只选择 `dist/content.js`。
4. 在普通 HTTPS 页面上，点击扩展图标启用 JotPatch。每次手动点击使用当前页临时授权；需要自动恢复可在设置页按站点授权。

Firefox 正式发行包尚未完成合并和签名；不要尝试直接安装 Chromium ZIP。

### 新建、编辑便签

- 选中文字 → 点击附近 📌；或选中文字后使用右键菜单。
- 没有选区：点击扩展图标后按 `+` 创建本页悬浮便签。
- 拖动便签顶部空白区域移动；右下角拖动调整大小；底部按钮可加粗、斜体和制作列表。
- `···` 菜单可以改颜色、字号、删除；删除后的短时间内可以撤销。
- 内容自动保存为本地 Markdown；工具栏可以复制 Markdown 原文。
- 在设置页选择新便签**固定黄色**（默认）或**随机颜色**（同一运行实例连续新建不会重复）。

## 在 ChatGPT / Gemini 中导航

- 灰色横条对应已发现的提问，彩色标记对应保存的便签。
- 悬停显示简短摘要；点击直接定位。
- 已浏览过但临时卸载的对话仍会保留在导航索引。点击后 JotPatch 会在有限范围内尝试向对应位置恢复；不保证 ChatGPT 总能重新加载。
- 虚线便签标记表示原文当前不在可检索的 DOM 中，**便签数据不会因此删除**。自动定位失败时不会跳到另一轮相似文字。
- 长会话「Navigation Lab」在设置里**默认关闭**，只建议测试人员主动开启。开启后使用另一种按需恢复策略，并允许手动滚动取消。

## 设置

从 JotPatch 迷你启动区中的 ⚙ 打开：

- 选区快捷图钉：总是显示 / 仅按 Alt 或 Option 时显示 / 关闭。
- 默认便签颜色：固定黄色 / 随机颜色。
- AI 会话导航：开启/关闭提问横条。
- Navigation Lab：测试中的长会话定位策略（默认关闭）。
- 自动恢复：对你指定的网站单独请求可选站点权限。

## 数据与升级

- 便签及偏好保存在 `chrome.storage.local`；不会自动跨浏览器同步，也没有账号云端备份。
- 升级现有**已解压安装**时，建议覆盖**原扩展目录**后点击扩展页「重新加载」，而不是删除扩展再换目录安装。后者可能导致扩展 ID 变化、本地便签不可见。
- 删除扩展或清空本地扩展数据可能丢失便签。没有数据导出功能时，应自行保留必要内容。
- ChatGPT/Gemini 的虚拟化或重绘可能临时卸载原文：JotPatch 会尽量保留便签内容与已发现导航；它不能绕过站点权限、强制恢复服务端未提供的历史。
- 不支持浏览器内建 `chrome://` 等受限页面以及无法访问的跨域 iframe 原文。

## 获取帮助

如发现无法跳转、重复灰条或便签位置异常，请提交 GitHub Issue，附上 JotPatch 版本名、浏览器版本、网站、重现步骤及可公开的控制台日志。**请先删去聊天正文、登录令牌、账号信息和其他私人数据。**


## Firefox 测试版安装

1. 从 GitHub Releases 下载 `JotPatch-v0.1.17-firefox.zip` 并解压。
2. 在 Firefox 142 或更新版本打开 `about:debugging#/runtime/this-firefox`，选择 **Load Temporary Add-on**，打开解压文件夹中的 `manifest.json`。
3. 浏览器重启后临时安装将被移除，扩展本地存储可能不能继续访问。若 Release 附有 **Mozilla 签名**的 `JotPatch-v0.1.17-firefox-signed.xpi`，应优先使用签名版正常安装。
4. Chrome/Edge 和 Firefox 的便签数据保存在各自浏览器中，**不会自动同步**。不要先卸载旧插件，避免数据丢失。

若 Release 只提供 Firefox ZIP 而未提供已签名的 XPI，则该 Firefox 包仅面向测试，不应当成普通用户可永久安装的插件。
