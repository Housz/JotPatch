# JotPatch 用户指南

JotPatch 将轻量便签保存在你正在阅读的网页旁。本文以 GitHub Release **v0.1.18** 的功能为基线。Firefox 的新 ZIP 仍需 Mozilla 手动签名，获取签名 XPI 后才能进行普通浏览器的长期安装。

## 安装

### Chrome / Edge

**前提**：支持扩展的 Chrome 或 Edge，使用 [最新 Release](https://github.com/Housz/JotPatch/releases/latest) 中的 Chromium ZIP。

1. 完整解压 `JotPatch-v0.1.18-chromium.zip`。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择**直接包含 `manifest.json`** 的目录。
4. 在普通 HTTP(S) 网页点击 JotPatch 图标，看到右上角的迷你启动区即表示已启用。

### Firefox

**前提**：Firefox 142 或更高版本。只有当 Release 中提供 **`JotPatch-v0.1.18-firefox-signed.xpi`**（Mozilla 签名）时，普通用户才能安装新版本；**`JotPatch-v0.1.18-firefox.zip` 是未签名包，用于开发临时加载及 Mozilla 提交**。若签名 XPI 尚未提供，请继续使用此前已经签名的 v0.1.17。

1. 打开 `about:addons`，在扩展管理页的齿轮菜单选择「从文件安装附加组件」。
2. 选择 XPI，确认浏览器的安装提示。
3. 打开普通 HTTP(S) 网页并点击 JotPatch 工具栏图标；首次启动应看到迷你启动区。
4. 重启浏览器后检查扩展仍在。签名 XPI 用于正常持久安装；`about:debugging` 加载的未签名 ZIP 仅为临时调试。**升级时不要先卸载原版，以保护本地便签数据。**

Firefox 的 ID、手动升级及已知发行差异见 [Firefox 专题](FIREFOX.md)。不同浏览器的便签数据不会自动同步。

## 创建与编辑便签

### 关联原文

1. 在普通网页中选中不超过 1600 字的原文。
2. 点击选区旁的 📌，或右键选择「📌 添加 JotPatch 便签」。
3. 便签创建在所选文本附近，输入时自动保存。返回同一网页后可从彩色标记定位；原文被网站卸载时，便签记录仍保留。
4. 顶栏空白处拖动便签，右下角拖动改变宽高；点击顶栏 Pin 图标可解除原文锚定，短时间内可撤销。

对于文字重复且无法可靠定位的右键选区，JotPatch 会要求重新选中原文，而不是随意关联到另一处。

### 本页悬浮便签

没有选择文字时，点击扩展图标，在迷你启动区点 `+`。这类便签属于**当前网页**，不是跨网页持续跟随的便签。

### 编辑格式与管理

- 编辑器支持加粗、斜体、无序列表和有序列表；保存内容为 Markdown 文本。
- 顶栏的复制按钮复制 Markdown 源码，关闭按钮收起便签但不删除。
- `···` 菜单用于颜色、小/中/大字号和删除；在便签上按 Ctrl + 鼠标滚轮可调整字号。
- 删除后可在短暂出现的提示条点击「撤销」。关闭或刷新网页可能使这次临时撤销机会结束。

### 数学公式和普通文字混选

在 ChatGPT 等使用 KaTeX 或可识别 MathML 的网页中，可以选中**整个公式**，或同时选中公式与前后普通文字，点击 📌 创建便签。

- JotPatch 优先读取网页渲染结果已有的 LaTeX 注释、`data-tex` / `data-latex` 等元信息，把一个公式当作一个完整的锚定单元。选中公式的一部分时按**整条公式**锚定，不保证精确到单个数学符号。
- 对重复公式仍使用前后文字与所属对话轮次核对位置；网页重新渲染相同公式后可尝试恢复，不会因为另一轮出现相同公式就自动关联。
- 网页若只留下无法解析的图片/SVG、没有可靠的 TeX/MathML 文本身份，或规范化选区超过 1600 字，仍可能无法创建锚点。可以改选公式旁边的可见文字，或用 `+` 创建本页悬浮便签。
- 数学支持在合成 KaTeX/MathML DOM 上执行 Chromium、Firefox 回归；真实登录 ChatGPT 的渲染可能随网站更新，问题反馈请附可公开的 DOM 结构和浏览器版本，勿上传私人聊天内容。

## ChatGPT / Gemini 导航

灰色短横条对应页面**已发现的用户提问**，彩色标记对应保存的便签。鼠标悬停只显示内容摘要，点击当前标记直接跳转。

在长对话中，网站可能动态移除旧消息 DOM。JotPatch 会保留已识别且具有稳定身份的轮次记录；用户点击历史目标后，才有界尝试找回该轮次。若原文未加载或匹配不可信，会提示暂时无法定位，不会因为相同文本出现在其他轮次就宣告成功。用户手动滚动可取消恢复。

`Navigation Lab` 位于设置中的「AI 会话导航」下，是 ChatGPT 的实验性恢复策略，**默认关闭**。它的合成模型测试不能说明所有真实会话均可恢复。

## 设置与授权

在迷你启动区点击 ⚙ 打开 JotPatch 设置页：

| 设置区域 | 行为 |
| --- | --- |
| 选中文字后的快捷图钉 | 总是显示（默认）/ 按住 Alt 或 Option 时显示 / 从不显示 |
| 默认便签颜色 | 固定黄色（默认）/ 随机颜色（尽量避免连续重复） |
| AI 会话导航 | 开关提问横条；不清除已存便签 |
| Navigation Lab | 实验性长对话恢复，默认关闭 |
| 自动恢复 | 为指定 HTTP(S) 网站单独请求可选站点权限，刷新后可自动注入 |

第一次通过工具栏点击启用，使用的是当前页临时授权；要让网页刷新后自动恢复，需要在「自动恢复」中授予对应网站权限。默认不请求访问全部网站。

## 数据与升级

- 便签和设置保存在扩展本地存储（Chromium 为 `chrome.storage.local`，Firefox 为 WebExtension `browser.storage.local`）；不上传聊天内容，也没有跨浏览器同步或自动备份。
- **手动更新 Chrome/Edge 解压版**：保留原扩展目录和身份，用新版本文件替换后，在扩展管理页点击「重新加载」并刷新目标网页。不要为了升级先卸载。
- **手动更新 Firefox**：安装同一 Firefox 扩展 ID、版本号更高的 Mozilla 签名 XPI；避免先卸载旧版。改变扩展 ID 会使原有本地数据不再自动对应到新扩展。
- 删除扩展、清除扩展数据或更换安装身份可能造成便签丢失。在尚无专门导出功能时，重要内容请另行备份。
- JotPatch 不会因为网页 DOM 卸载而主动删除便签。存储结构兼容要求见 [架构说明](ARCHITECTURE.md)。

## 常见问题与排查

| 现象 | 检查方法与下一步 |
| --- | --- |
| 点击图标没有出现便签 | 先在普通 HTTP(S) 页面测试；浏览器内部页如 `about:newtab`、`chrome://extensions` 不支持注入。再到扩展错误控制台查 JotPatch 堆栈。 |
| Firefox 显示未签名或无法长期保留 | 确认安装的是 Release 中实际提供的 `-firefox-signed.xpi`，不是 `JotPatch-v0.1.18-firefox.zip` 开发 / 签名候选包。参阅 [Firefox 说明](FIREFOX.md)。 |
| 刷新网页后需要重新点图标 | 在「自动恢复」中为该网站授权，再刷新网页。 |
| 导航没有列出所有历史提问 | 默认只记住页面已经暴露的轮次；正常浏览旧消息后才逐步加入，不会后台自动扫描全历史。 |
| 原文便签暂时不显示 | 检查原文是否已被网站动态卸载；通过导航明确请求恢复。不要删除旧便签重建。 |
| 升级后找不到旧便签 | 先确认是否用了相同浏览器配置、扩展 ID 和网页地址；不要立刻清理旧扩展数据。 |
