# JotPatch v0.1.19 — 轻量一体化 Dock 设计与验收

## 目标与需求来源

本开发任务对应 [Issue #34：UI 优化](https://github.com/Housz/JotPatch/issues/34)。此前 JotPatch 的右上角 `+ / ⚙ / −` 小控制区，与网页右侧的对话/便签导航轨道分离。用户需要记住两处入口；无便签页面又无法通过原导航条开始新建便签。

本版的核心用户心智是：**就地选中原文 → 📌 写便签；没有选区 → Dock + 新建本页便签；需要返回 → 点击导航标记；调整全局行为 → Dock 设置。** 让用户的注意力回到正在阅读的网页。

本 PR 只处理统一 Dock（第一阶段）。[Issue #36：轨道便签右键删除](https://github.com/Housz/JotPatch/issues/36)、[Issue #33：透明度档位](https://github.com/Housz/JotPatch/issues/33)仍作为独立任务；不在本次改动中实现，避免将删除行为或设置偏好混入结构性重构。聊天导出研究 [#35](https://github.com/Housz/JotPatch/issues/35)不在范围内。

## 交互状态

| 页面状态 | 右侧 Dock | 用户可执行操作 |
| --- | --- | --- |
| 没有便签，也没有足够的对话轮次 | **空状态，短条** | `+` 新建本页悬浮便签；`⚙` 打开设置 |
| 仅有本页悬浮/待定位便签 | **紧凑条** | `+`、`≡` 打开便签列表、`⚙` |
| 有可定位便签 | **完整轨道** | `+`、`≡`、彩色便签点、`⚙`；点击点立即定位 |
| 有至少三轮识别到的 AI 提问 | **完整轨道** | 灰色提问线、彩色便签点，点击直接导航 |
| 网页已经提供识别可靠的原生对话导航 | 保留 Dock 基础操作，避免重复灰条 | 本页便签仍可访问 |
| 浏览器工具栏再次点击 | 整体隐藏/显示 | 不清除便签、存储或网站授权 |

## 行为原则

1. **唯一管理入口**：删除单独的浮动 Launcher，不保留第二个 `+ / ⚙ / −` 按钮组；浏览器工具栏图标控制整个 UI 显隐。
2. **工具与原文语义不混用**：Dock `+` 永远创建本页悬浮便签；选区旁 📌 只建立原文锚点。两条路径都可独立完成任务。
3. **直接导航优先**：所有已存在的灰色轮次与彩色便签点仍一键到达；不恢复以前移除的鱼眼、合并点、二级选择列表。
4. **降低次级操作噪音**：列表在需要时出现，Esc、点击页面外部或关闭按钮可结束；列表在键盘关闭后归还焦点。
5. **保留数据与身份**：保持 `jotpatch:note:v1:*`、`jotpatch:preferences:v1`、`Note.schemaVersion:1`，以及 Firefox 已签名的固定扩展 ID。
6. **保持轻量**：不新增 UI 框架、不使用 `backdrop-filter` 背景模糊、没有常驻复杂动画；仍依赖现有节流扫描与轨道布局计算。

## 验收矩阵

| 类型 | 情景 | 主要断言 |
| --- | --- | --- |
| 基础交互 | 普通空白网页首次安装 | Dock 可见；`+`、设置可点击；无空白长轨道 |
| 便签生命周期 | 新建悬浮便签 → 编辑保存 → 隐藏/显示 | 无重复内容脚本、Note 存储未丢失 |
| 文字锚定 | 普通文字选区 → 📌；KaTeX/MathML 混合选区 | 锚定语义与旧版一致 |
| 导航 | 有 3+ / 120 个提问的 ChatGPT/Gemini 合成页 | 灰色横条、彩色点、直接点击跳转保持正常 |
| 列表操作 | 点击 / Enter / Escape / 点击外部 | 正确开合、`aria-expanded` 和焦点恢复 |
| 原生导航 | 站点提供自身时间线 | 不重复绘制 JotPatch 灰色横条 |
| 窄屏 | 360px 宽浏览器 | Dock 不越出右侧，可点击操作 |
| 数据兼容 | 页面刷新 / 重启 Firefox 临时安装用例 | 便签持久保存且同一 ID 下恢复 |
| 工程验收 | `npm run check`、跨浏览器 E2E、Firefox MV3 Selenium | 无 TypeScript/Node 失败、浏览器异常或 lint 错误 |

执行记录须对应本 PR 最新提交的 GitHub CI；只运行合成浏览器测试不能宣称已验证登录的 ChatGPT/Gemini 页面。

## 已知限制

- 页面关闭或刷新后，是否自动恢复可见 UI 由该网站已授予的权限与内容脚本生命周期决定；JotPatch 没有新增自动更新或云同步机制。
- 在较窄的轨道上，多轮对话依然通过现有三轨错位保持独立点标记。密集标记操作需要保留完整列表替代入口。
- 右键删除与透明度档位属于后续任务；本次不改变便签删除权限和透明度偏好。
- 发布后需要普通 Chrome/Edge 与签名 Firefox 的实际用户体验验收；当前只在开发分支实现。
