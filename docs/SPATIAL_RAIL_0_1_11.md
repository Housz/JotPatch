# JotPatch v0.1.11 — Spatial Rail / 连续空间导航

## 设计与边界

**一张便签始终一个导航标记**。灰色横线代表一轮用户提问，彩色短线代表在本轮原文不同位置留下的便签。轨道保留严格上下顺序及原文相对进度。新便签不会让旧便签重新以第一张/最后一张重新归一化。任何数量的便签均不自动合并为彩色分段胶囊，不出现需要二次选择的弹出列表。

只有导航项目实际出现视觉碰撞、可点击间距太小时，才启用 **单轴连续鱼眼放大**：鼠标靠近局部，当前轨道里的近处标记自然分散，远处相对压缩，仍保留顶部、底部、焦点位置及全部标记的相对顺序；鼠标移开后恢复基础坐标。展开列表仍可通过顶部入口主动查看，但不是点击密集便签的前置步骤。

## 位置的三层来源（用户心智优先）

- **所属轮次**：首先尝试匹配真正的用户 Prompt 及相邻 AI 回复的 DOM 区域，保存可用的稳定 `conversationTurnId`。
- **轮次内比例**：优先以相对于“本轮 Prompt 顶部 → 下一轮 Prompt 顶部”的几何高度计算，包含代码块和图片带来的实际屏幕长度；仅当两端可信且锚点在范围内才接受。次选对应整轮文本偏移百分比，而非当前几张便签的首尾偏移。
- **没有可靠轮次或原文暂时不可定位**：兼容旧记录，已有比例沿用；可识别页面级比例的便签在普通文档里保留位置；没有来源比例的便签放在轨道底部的待定位入口，绝不默认塞在 50%、90% 等伪造位置。

可选字段 `Note.spatial?: {withinTurnProgress?:number; pageProgress?:number; confidence:'geometry'|'text'|'estimated'}` 与原来的 `conversationTurnId?:string` 向后兼容。`Note.schemaVersion` 保持为 `1`；已有内容、颜色、编辑器及 Pin/Unpin 行为不受影响。关闭/卸载扩展会影响本地存储，不提供云同步。

## 轨道布局算法

- `src/content/rail-layout.ts`：纯函数 `layoutConversationRail()` 将每轮基础间距和便签数量作为有限权重，得到动态的轮次空间。`placeOrderedMarkers()` 在保持原文顺序和接近真实比例的前提下，通过 PAVA（有序最小二乘约束）消解碰撞。前部 5%/7%/9% 的便签仍靠前，10%/50%/90% 仍分别位于前/中/后。
- 当 `minPitch < 9px`，启用 `fisheyePositions()`，使用严格单调的焦点居中变换；不改变列表/页面 DOM、不启动自动滚动、不合并项目。使用约 2px 网格的公共积分表，每帧开销接近 `O(trackHeight + markerCount)`。
- `src/content/app.ts` 渲染所有独立 marker，并在指针进入导航栏时通过 `requestAnimationFrame` 低延迟更新。指针按下后锁定焦点，命中优先使用可见 marker；透明边缘提供最近标记选择。交互期间冻结 DOM 结构性重排，退出轨道再刷新，以减少 ChatGPT 流式输出/虚拟化带来的标记跳跃。支持 ArrowUp/Down、Home/End 和 Enter，尊重 reduced-motion。
- ChatGPT / Gemini 被动轮次索引仍只读取已经加载或浏览过的 DOM。**不保证扫描全部历史消息**；没有后台隐形自动滚动或调用私有接口。

## 已知限制

- 相对几何位置必须有可信轮次边界。网页动态加载、渲染不完整、消息被折叠或 AI 正生成时，比例可能暂时使用上次可靠值或降级至文本比例。离屏老消息只能通过稳定 ID / 已保存比例尝试回找，不能假装能够导航到未加载的数据。
- 高密度的全局概览在物理像素层面无法保证每个标记始终有独立 24px 命中区域；鱼眼局部展开和顶部主动列表是可访问性补偿，而不是另加一套强制交互。
- Chromium 的 `contenteditable` 编辑器是既有实现，本次未重写其输入法、撤销等边界。阶段 2 跨网页 Follow 模式仍未开发。

## 测试 / 审核

```
npm run check
npm run test:e2e
```

测试包含 22 项 Node 契约/几何单元测试，5 组 Chromium Playwright 脚本，包括：

- 12 轮聊天，10/50/90% 和 5/7/9% 便签，在 640/850/1080px 窗口验证秩序与比例。
- 动态插入新便签与存储恢复，不会按已存在便签首尾位置重新映射旧标记。
- 100 轮 / 60 张便签下的真实鼠标连续鱼眼、同轨放大、无二次弹层、一键点击对应纸张、离开后归位、resize、键盘导航。
- 原有 ChatGPT/Gemini DOM 适配、自然滚动索引、WYSIWYG Markdown、剪贴板、颜色、Pin/Unpin 和 DOM 虚拟化防误弹回归。

这些是**合成 DOM** 的浏览器测试，不等于实际登录 ChatGPT/Gemini 且处于不同实验版本下的安装态验收。真实 Chrome/Edge 的权限、站点更新和扩展 Service Worker 仍需本机检查。
